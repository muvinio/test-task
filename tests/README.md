# 🧪 Универсальный набор тестов для проверки X-Forwarded-For

## Структура
- `run.sh` – главный скрипт, последовательно запускает все категории тестов.
- `helpers.sh` – вспомогательные функции (отправка запроса, проверка ответа, цветной вывод).
- `direct.sh` – тесты прямых маршрутов (один прокси → приложение).
- `chain.sh` – тесты цепочек из 2 и 3 прокси (все возможные комбинации).
- `spoofing.sh` – тесты защиты от подделки заголовка `X-Forwarded-For`.

## Требования
- `bash` 
- `curl` 

## Запуск
1. Убедитесь, что контейнеры работают.
2. Перейдите в корень проекта (где находится `docker-compose.yml`).
3. Выполните:
   ```bash
   ./tests/run.sh
